# Civ 5 Drafter

A simple random civilization drafter for Sid Meier's Civilization V multiplayer games. Inspired by Fruitstrike's Fabulous Civ 5 Drafter.

## Features

- Pick number of players (2–12) and civs per player (1–5)
- Ban any civs you don't want in the pool
- Quick filters: Venice Only, None, All, Inverse
- Optional duplicate civs across players
- All 43 Brave New World + DLC civs

## Run locally

It's a static site — open `index.html` in a browser, or serve it:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000.
